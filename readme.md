
# Project 1: PDF Question Answering using RAG

## Objective
Build a Retrieval-Augmented Generation (RAG) application that answers questions from PDF documents.

## Concepts Covered
- Document loading and text extraction
- Text chunking
- Text embeddings
- Vector similarity search
- Retrieval-Augmented Generation
- LLM integration

## Technology Stack
- Python
- Sentence Transformers
- FAISS / Chroma
- LLM APIs
